# n8n-nodes-contactwise

n8n community nodes for [ContactWise](https://docs.contactwise.io/): send DLT-compliant SMS to Indian mobile numbers from your n8n workflows and AI agents.

> **Status: in development.** Not yet published to npm. Full usage docs, credential setup and example workflows will land before the first release.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/sustainable-use-license/) workflow automation platform.
